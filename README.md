# UMI Internship Project

## Project Overview

This repository documents my internship work on **Project-UMI** (Universal Manipulation Interface), a robotics project focused on developing and improving robotic manipulation systems.

**Internship Period:** June 1, 2024 - August 2024

## Scope of Work

The internship focused on prototyping and optimizing the Stanford UMI gripper system:

* **Prototyped Stanford UMI Gripper**: Adapted the Universal Manipulation Interface gripper design for UR5 robot integration
* **Redesigned Components**: Optimized gripper mount parts for improved assembly and functionality
* **Weiss WSG-50 Integration**: Developed and refined the gripper mount specifically for the Weiss WSG-50 gripper
* **Testing & Validation**: Conducted assembly tests and performance validation

## About Project-UMI

Project-UMI (Universal Manipulation Interface) is Stanford's framework for developing intuitive and effective robotic manipulation systems. This internship focused on prototyping the UMI gripper for the UR5 robot platform, specifically:

- **Gripper Mount Redesign**: Optimized the mounting interface between the Stanford UMI gripper and the Weiss WSG-50 parallel gripper
- **UR5 Integration**: Adapted the UMI system for seamless integration with Universal Robots' UR5 platform
- **Assembly Optimization**: Redesigned key components to simplify assembly process and improve mechanical reliability

The work contributed to making the UMI gripper more accessible and easier to deploy on standard industrial robot platforms.
